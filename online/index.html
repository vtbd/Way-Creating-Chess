棋谱

    联机版与单机版共用同一份规则引擎（js/engine.js），后端只保存“着法列表”，两边各自重放得到棋局， 因此刷新、断线重连、中途加入都只需要重新拉一次列表。

    需要通过本地服务器或 GitHub Pages 打开

    这个页面使用 ES 模块，直接双击 online/index.html（file://）会被浏览器拦截。

    node tools/serve.mjs

    然后访问 http://localhost:8000/online/。
