棋谱

    点击任意一步可在棋盘上高亮该手与它造出的道路。

    规则与桌面版 game_engine.py 一致：在“可走”格落子后自动造路，先连成四子者获胜。 棋盘可随机生成、手动编辑，也能把当前局面存成新的初始棋盘。

    需要通过本地服务器或 GitHub Pages 打开

    这个页面使用了 ES 模块与 Web Worker，直接双击 index.html（file:// ）会被浏览器拦截。请在项目目录执行任意一条命令，再访问提示的地址： 

    node tools/serve.mjs
    npx serve .        （或：py -m http.server 8000）

    然后打开 http://localhost:8000/。部署到 GitHub Pages 后可直接访问网址，无需任何额外配置。
